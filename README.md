## 📖 项目简介

互联网每天都会涌现大量新词热梗（"内卷""破防""显眼包""松弛感"……），普通人很难跟上节奏。
查搜索引擎结果碎片化、百度百科太学术、问别人又不好意思——梗百科正是为解决这个痛点而生。

输入任何不懂的词汇，AI 即刻用「说人话」的方式给出结构化解释：**含义、出处、例句、分类标签**，10 秒完全理解一个新词。

## ✨ 功能展示

| 功能 | 说明 |
|------|------|
| 🔍 **AI 智能解释** | 输入任意词/短语，返回含义、出处、例句、标签的结构化解析 |
| 🧠 **自生长知识库** | 每解释一个新词自动沉淀入库，搜索越多越聪明，热词榜按真实热度排序 |
| 🌐 **联网搜索兜底** | 词库未命中时自动联网检索真实信息（无需 API Key） |
| 🎤 **语音输入** | 支持中文语音识别，懒得打字也能搜 |
| 🔥 **热词排行榜** | 按真实搜索热度动态排序的 TOP 15 榜单 + 知识库统计面板 |
| ⭐ **收藏夹** | 收藏感兴趣的解释，随时回顾 |
| 🎴 **分享卡片** | 一键生成精美解释卡片，复制分享 |
| 🌙 **暗色/亮色主题** | 一键切换，护眼更舒适 |
| 🖥 **PWA 安装** | 一键安装到桌面 + Service Worker 离线缓存 |
| 🔑 **前端直配 API** | 页面内直接粘贴 DeepSeek / OpenAI / 自定义接口的 API Key，无需改代码 |

## 🛠 技术架构

```
┌─────────────────────────────────────────────┐
│                  前端 (SPA + PWA)             │
│   index.html + style.css + app.js            │
├─────────────────────────────────────────────┤
│  AI 引擎（三级智能降级策略）                   │
│  ┌──────────┬──────────┬────────────────┐   │
│  │ 知识库    │ LLM API │ 联网搜索(DDG)   │   │
│  │ (种子+   │ (Deep-  │ (兜底)          │   │
│  │  自生长) │  Seek)  │                │   │
│  └──────────┴──────────┴────────────────┘   │
├─────────────────────────────────────────────┤
│  本地存储 (localStorage)                     │
│  历史 / 收藏 / API配置 / 知识库 / 搜索计数     │
└─────────────────────────────────────────────┘
```

- **前端**：原生 HTML/CSS/JS 单页应用，零框架、零依赖
- **AI 引擎**：三级策略 —— `LLM API → 联网搜索 → 模板生成`，无论有无 API Key、有无网络都能工作
- **PWA**：Service Worker + manifest.json，支持离线使用和桌面安装
- **存储**：纯前端 localStorage，无需后端、无需数据库

### 自生长知识库机制

```
用户搜索新词 → 知识库已有？ ──有──→ 直接秒回
                  │
                无 ↓
       LLM API / 联网搜索 → 生成解释 → 自动入库 🌱
                                       │
                                 下次搜索秒回 + 热度 +1
```

## 🚦 快速开始（本地运行）

无需安装任何依赖，项目是纯静态文件。

### 方式一：Python（推荐）

```bash
cd d:\Trea_project
python -m http.server 3000
```

浏览器访问 `http://localhost:3000`

### 方式二：VS Code Live Server

右键 `index.html` → `Open with Live Server`

### 方式三：Node.js

```bash
npx serve .
```

> ⚠️ 注意：直接双击 `index.html` 打开可能因浏览器安全策略无法加载部分资源，请使用本地服务器方式访问。

## 🔑 配置 AI API（可选）

项目内置 15 个种子热词 + 联网搜索兜底，**开箱即用无需配置**。想获得更高质量的 AI 回答，可在页面内直接配置：

1. 点击页面右上角 **`● API`** 按钮
2. 选择模型提供商：DeepSeek（推荐）/ OpenAI / 自定义兼容接口
3. 粘贴 API Key（自定义接口还需填写 Base URL 和模型名）
4. 点击「保存并连接」→ 状态灯变绿即连接成功

API Key 仅保存在浏览器本地（localStorage），不会上传到任何服务器。

## 📦 部署上线

项目为纯静态站点，可部署到任何静态托管平台。

### 方案一：Vercel（当前已使用）

1. 推送代码到 GitHub 仓库
2. 打开 [vercel.com](https://vercel.com) → **New Project** → 导入该仓库
3. Vercel 自动识别静态站点并完成部署，生成 `xxx.vercel.app` 链接

### 方案二：Netlify Drop（无需代码托管）

打开 [app.netlify.com/drop](https://app.netlify.com/drop)，把整个项目文件夹拖进去，5 秒即可得到线上链接。

### 方案三：GitHub Pages

将项目推送至 GitHub 仓库 → Settings → Pages → 选择 `main` 分支的根目录，即可获得 `https://用户名.github.io/仓库名/` 链接。
